# Internationalization

## Supported Languages

The SDK supports three languages:

| Code | Language |
|------|----------|
| `uz` | Uzbek |
| `ru` | Russian |
| `en` | English |

## Setting the Locale

```typescript
import { getLocale, setLocale } from '@eimzo/core'

// Set locale manually
setLocale('uz')

// Get current locale
const currentLocale = getLocale() // 'uz'
```

## Auto-detect Browser Language

```typescript
import { detectAndSetBrowserLocale } from '@eimzo/core'

// Automatically detect and set locale from browser settings
detectAndSetBrowserLocale()
```

## Getting Error Messages

```typescript
import { getErrorMessage, setLocale } from '@eimzo/core'

// Get localized error message
setLocale('uz')
const message = getErrorMessage('CONNECTION_ERROR')
// "E-IMZO ilovasi ishlamayapti"

setLocale('ru')
const messageRu = getErrorMessage('CONNECTION_ERROR')
// "Приложение E-IMZO не запущено"
```

## Available Error Keys

| Key | Uzbek | Russian | English |
|-----|-------|---------|---------|
| `CONNECTION_ERROR` | E-IMZO ilovasi ishlamayapti | Приложение E-IMZO не запущено | E-IMZO application is not running |
| `TIMEOUT_ERROR` | Amal vaqti tugadi | Время операции истекло | Operation timed out |
| `CERTIFICATE_ERROR` | Sertifikat xatosi | Ошибка сертификата | Certificate error |
| `CERTIFICATE_EXPIRED` | Sertifikat muddati tugagan | Сертификат истек | Certificate has expired |
| `PIN_CANCELLED` | PIN kiritish bekor qilindi | Ввод PIN отменен | PIN entry cancelled |
| `SIGNING_ERROR` | Imzolashda xatolik | Ошибка подписания | Signing error |

## Checking Locale Support

```typescript
import { getSupportedLocales, isLocaleSupported } from '@eimzo/core'

// Check if locale is supported
isLocaleSupported('uz') // true
isLocaleSupported('de') // false

// Get all supported locales
getSupportedLocales() // ['uz', 'ru', 'en']
```

## Custom Messages

You can extend the i18n system with custom messages:

```typescript
import { i18n } from '@eimzo/core'

// Add custom messages
i18n.addMessages('uz', {
  CUSTOM_ERROR: 'Maxsus xatolik xabari',
  SUCCESS_MESSAGE: 'Muvaffaqiyatli!'
})

i18n.addMessages('ru', {
  CUSTOM_ERROR: 'Пользовательское сообщение об ошибке',
  SUCCESS_MESSAGE: 'Успешно!'
})
```

## Vue Integration

### Locale Selector Component

```vue
<script setup lang="ts">
import { getLocale, getSupportedLocales, setLocale } from '@eimzo/core'
import { ref, watch } from 'vue'

const currentLocale = ref(getLocale())
const locales = getSupportedLocales()

const localeLabels: Record<string, string> = {
  uz: 'O\'zbekcha',
  ru: 'Русский',
  en: 'English',
}

watch(currentLocale, (newLocale) => {
  setLocale(newLocale)
})
</script>

<template>
  <select v-model="currentLocale">
    <option v-for="locale in locales" :key="locale" :value="locale">
      {{ localeLabels[locale] }}
    </option>
  </select>
</template>
```

### Composable with i18n

```typescript
import { getErrorMessage } from '@eimzo/core'
import { useESignature } from '@eimzo/vue'
import { computed } from 'vue'

export function useESignatureWithI18n() {
  const eSignature = useESignature()

  const localizedError = computed(() => {
    if (!eSignature.error.value)
      return null
    return getErrorMessage(eSignature.error.value)
  })

  return {
    ...eSignature,
    localizedError,
  }
}
```

## Server-Side Rendering

For SSR applications (Nuxt), detect locale on the server:

```typescript
// plugins/eimzo-i18n.ts
import { setLocale } from '@eimzo/core'

export default defineNuxtPlugin(() => {
  const { locale } = useI18n()

  // Sync E-IMZO locale with Nuxt i18n
  watch(locale, (newLocale) => {
    if (['uz', 'ru', 'en'].includes(newLocale)) {
      setLocale(newLocale as 'uz' | 'ru' | 'en')
    }
  }, { immediate: true })
})
```
